# LDR-sensor
LDR Sensor – Bright and Dark Detection 
# About the Project
This is a simple Arduino project using an LDR (Light Dependent Resistor) to detect changes in surrounding light.The LDR senses the amount of light falling on it and sends changing values to the Arduino. Based on a set threshold value, the Arduino identifies the environment as BRIGHT or DARK and displays the result on the Serial Monitor.
# Components Used
- Arduino Uno
- LDR Sensor
- Jumper Wires
- Breadboard
# How It Works
1. The LDR senses the surrounding light.
2. Arduino reads the sensor value.
3. The reading is compared with a predefined threshold.
4. Based on the reading, it prints BRIGHT or DARK on the Serial Monitor.
